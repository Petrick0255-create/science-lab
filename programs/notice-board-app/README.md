# 공지 모음 웹앱

팀장님·실장님·총무님의 공지를 날짜, 작성자, 최신순/오래된순으로 확인하고 파일을 함께 보관하는 Google Apps Script 웹앱입니다.

## 설치

1. [Google Apps Script](https://script.google.com/)에서 **새 프로젝트**를 만듭니다.
2. 기본 `Code.gs` 내용을 이 폴더의 `Code.gs`로 교체합니다.
3. 왼쪽 `+` → **HTML**을 눌러 파일 이름을 `Index`로 만들고 `Index.html` 내용을 붙여 넣습니다.
4. 프로젝트 설정에서 **appsscript.json 매니페스트 파일을 편집기에 표시**를 켠 뒤, 이 폴더의 `appsscript.json` 내용으로 교체합니다.
5. 함수 선택 메뉴에서 `setup`을 한 번 실행하고 Google 권한을 허용합니다. 지정된 공지 모음 폴더 안에 `공지 모음 DB` 시트와 `공지 첨부파일` 폴더가 자동 생성됩니다.
6. 오른쪽 위 **배포 → 새 배포 → 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** 또는 조직 정책상 허용되는 가장 넓은 범위
7. 배포된 웹 앱 URL을 사내에 공유합니다.

## 동작 방식

- 공지 본문과 작성자, 날짜, 첨부 정보는 `공지 모음 DB` 시트에 저장됩니다.
- 실제 파일은 `공지 첨부파일/날짜_공지ID` 폴더에 저장됩니다.
- 첨부 합계는 공지 1건당 300MB까지 허용합니다.
- 큰 파일은 4MB 단위로 분할 전송하므로 업로드 중에는 브라우저 탭을 닫지 마세요.
- 공지 목록은 페이지 진입, 탭 재진입, 새로고침 버튼을 누를 때 시트와 다시 동기화됩니다.

## 주의

- 익명 웹앱 배포를 허용하면 URL을 아는 사람은 누구나 공지를 등록할 수 있습니다. 사내 메신저에만 공유해도 URL이 외부로 유출되면 작성이 가능합니다.
- Google Workspace 관리자가 익명 Apps Script 웹앱을 차단한 회사 계정에서는 `모든 사용자` 옵션이 나오지 않을 수 있습니다.
- 300MB 업로드는 네트워크 상태와 Apps Script/Drive 일일 할당량의 영향을 받습니다. 자주 대용량 파일을 올리는 용도라면 별도 저장 서버가 더 안정적입니다.
