# v26 배포 안내

## 수정 사항
- PDF에 이미지 파일로 저장되지 않은 그래프·실험 장치도 선과 도형을 분석해 캡처합니다.
- 화학 구조식처럼 글자와 결합 기호로 구성된 그림도 감지합니다.
- 그림 바깥의 (가)·(나), A·B·C, 그래프 축 이름을 함께 포함합니다.
- 선택지 그래프는 해당 선택지 번호를 포함하고 원본의 읽기 순서로 정렬합니다.
- 페이지·문항·열의 경계를 기준으로 범위를 제한하고, 본문 테두리와 흰색 덮개는 제외합니다.
- 원본 PDF에서 최대 2,800픽셀로 직접 렌더링해 무손실 PNG로 넣습니다. 원본 자체가 저해상도 이미지라면 원본의 세부 정보가 늘어나지는 않습니다.
- 기본 빈 표의 테두리는 4.5pt이며 미리보기에도 같은 비율로 적용됩니다. PDF에서 캡처한 그림 안의 표 선은 원본 그대로입니다.
- 기존 글자 추출 지시문·요청·응답 처리, 번호 스타일·번 선택·글자 크기 기능은 유지합니다.

## 배포 방법
1. ZIP을 압축 해제합니다.
2. 기존 사이트의 `programs/exam-pdf-to-ppt/`에 압축 안의 `exam-pdf-to-ppt/index.html`과 `exam-pdf-to-ppt/assets/` 전체를 덮어씁니다.
3. 기존 저장소의 배포 방식으로 변경 사항을 반영합니다. 여러 프로그램을 함께 서비스하는 Worker의 설정은 덮어쓰지 마세요.
4. 앱 전용 Worker를 이 폴더에서 배포해 왔다면 기존 Worker 이름을 확인한 뒤 `npm ci`, `npx wrangler deploy`를 실행합니다. `public-site/`에도 동일한 v26 배포 파일을 반영했습니다. 인증과 API 코드는 변경하지 않았습니다.
5. Ctrl+F5로 새로고침하고 화면에 **v26**이 표시되는지 확인합니다. PDF를 다시 분석해 새 PPT를 내려받으세요. 이미 만든 PPT는 자동으로 바뀌지 않습니다.

## 개발·검증
실제 활성 소스는 `assets/index-v26.js`, `assets/image-tools-v26.js`, `assets/pdf-figures-v26.js`, `assets/images-v26.css`입니다. 수정 후 `npm run build:v26`으로 배포 파일을 갱신합니다. 이전 `src/`를 단순히 `npm run build`로 빌드하면 최신 변경 사항이 반영되지 않으므로 v26 전용 빌드를 사용하세요.

제공된 통합과학 PDF, 생명과학 3S1603.pdf, 화학 3H1706.pdf의 실제 PDF 요소를 브라우저에서 감지·캡처하여 원본과 대조했습니다. 화학의 모식도·그래프·장치·구조식과 생명과학의 이름표 누락을 확인했고 34개 자동 검사가 통과했습니다. 브라우저에서 미리보기, 범위 수정, 반전, PPT 다운로드도 확인했습니다. PPT 내부 표 테두리는 4.5pt입니다.

검증 중 글자 분석 서버 응답만 자체 테스트 문항으로 대체했습니다. 그림 좌표는 대체하지 않았으며 실제 Gemini 서버의 글자 추출 결과까지 검증한 것은 아닙니다. 사용자가 언급한 화학 PPT 경로의 파일은 로컬에 없어 그 파일 자체와 비교하지 못했습니다.

모든 PDF 형식을 보장하는 방식은 아닙니다. 스캔 PDF처럼 문항 번호의 글자 정보가 없는 파일이나 복잡하게 겹친 도형은 자동 감지가 제한될 수 있습니다. 앱의 문항별 캡처 범위 수정 기능으로 보정할 수 있습니다.
