# v27 배포 안내: 편집 가능한 원본 표

표를 캡처 이미지로 넣지 않고 PowerPoint의 실제 표 객체로 생성합니다. 테두리 기본값은 2.25pt입니다.

## 사용 방법
1. 기존과 같이 PDF를 분석합니다. 표가 있으면 표 구조 탐지와 셀 내용 인식 단계가 추가됩니다.
2. 문항 편집 화면에서 표의 셀 내용을 확인하고 수정합니다. 위첨자는 `<sup>`, 아래첨자는 `<sub>` 태그로 수정할 수 있습니다.
3. PPT를 내려받으면 PowerPoint에서 셀 내용과 표 구조를 편집할 수 있습니다.

PDF에 저장된 선으로 행·열과 병합 셀을 찾고 Gemini에 표 셀 내용만 별도로 요청합니다. 본문 전사 지시문과 처리 기능은 유지했습니다. 열 너비 비율을 반영하며, 표를 읽으면 기존의 빈 2행×3열 표를 교체합니다. 표에 포함된 중복 그림 캡처는 제외합니다. 테두리가 없는 표나 스캔 이미지로 저장된 표는 현재 구조 탐지가 제한됩니다. 복잡한 수식은 원본과 대조하세요. 분수는 의미를 보존하는 분자/분모 표기로 들어갑니다.

셀 인식이 실패하면 실패 안내와 기존 빈 표를 남깁니다. 깨진 PDF 문자 정보를 인식에 성공한 것처럼 삽입하지 않습니다. 오류가 발생하면 다시 분석하거나 빈 표의 내용을 직접 입력할 수 있습니다.

## 배포
압축 안의 `exam-pdf-to-ppt/index.html`과 `exam-pdf-to-ppt/assets/` 전체를 기존 사이트 `programs/exam-pdf-to-ppt/`에 덮어쓰고 기존 방식으로 배포합니다. 앱 전용 Worker에서 배포해 왔다면 기존 설정을 확인한 뒤 해당 폴더에서 `npm ci`, `npx wrangler deploy`를 실행합니다. `public-site/`에도 v27 파일이 반영되어 있습니다. 여러 프로그램용 Worker 설정은 덮어쓰지 마세요.

배포 후 Ctrl+F5로 새로고침하고 v27 표시를 확인한 뒤 PDF를 다시 분석해야 합니다. 이미 생성된 PPT에는 소급 적용되지 않습니다.

활성 소스: `assets/index-v27.js`, `assets/native-tables-v27.js`, `assets/pdf-figures-v27.js`, `assets/image-tools-v27.js`, `assets/images-v27.css`. 재빌드: `npm run build:v27`. 이전 개발용 `src/`를 빌드하는 `npm run build`는 사용하지 마세요.

## 검증 범위
- 화학 3H1706.pdf에서 9·13·17·19·20번 표의 실제 선과 병합 구조를 탐지했습니다.
- 시험용 셀 인식 응답을 사용해 웹앱 셀 편집, 위첨자 표시, PPT 다운로드를 확인했습니다.
- 생성된 PPT 내부에 실제 표 5개, 병합 속성, 수정한 셀 내용, 2.25pt 테두리가 저장되는 것을 확인했습니다.
- 38개 자동 검사가 통과했습니다.
- 실제 Gemini 서버의 표 내용 인식은 이 환경에서 실행하지 않았습니다. 실제 PDF의 셀 내용을 모두 정확히 인식한다고 보장하는 검증은 아닙니다.
