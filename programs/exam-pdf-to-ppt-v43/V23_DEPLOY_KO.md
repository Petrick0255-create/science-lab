# v23 그림 캡처 기능

## 바뀐 점

기존 글자 추출용 지시문, 응답 처리, 첨자 처리, 텍스트 검증 코드는 v22 그대로입니다. 그림 처리는 별도 단계로 추가했습니다.

- PDF 분석 후 문항별 그림 영역을 별도 AI 요청으로 찾습니다. 설명 상자 안의 그림, 치수, 화살표, 그림에 딸린 표시도 찾도록 지시합니다.
- 좌표에 해당하는 원본 PDF 영역을 브라우저에서 고해상도 PNG로 캡처합니다. 그림을 새로 그리거나 생성하지 않습니다.
- 기본은 색상 반전입니다. 그림별로 원본 색상으로 되돌릴 수 있습니다.
- 문항 편집 아래 `문항 그림`에서 직접 드래그 캡처, 범위 수정, 크기 선택, 포함/제외, 삭제가 가능합니다.
- 기존 텍스트 위치를 유지하면서 빈 공간에 그림을 넣습니다. 공간이 부족하면 해당 문항의 그림 슬라이드를 추가합니다.
- 내려받은 PPT의 그림은 이동·크기 조절 가능한 이미지입니다. 그림 속 글자는 이미지에 포함됩니다.
- v22의 번호 스타일, 번 표시, 2pt 단위 크기 조절, 번호 정렬을 유지합니다.

## 사용 방법

1. PDF를 선택하고 기존처럼 `Gemini로 문항 분석`을 누릅니다.
2. 기본으로 켜져 있는 `분석 후 그림 자동 캡처`를 사용하면 글자 추출 후 그림을 추가합니다. 꺼두면 기존 글자 추출만 수행합니다.
3. 문항별 `문항 그림`의 캡처 결과를 확인합니다. 빠진 그림은 `PDF에서 직접 캡처`로 추가할 수 있습니다.
4. 범위가 잘못 잡힌 그림은 `캡처 범위 수정`에서 페이지를 고르고 영역을 드래그한 뒤 `이 영역 사용`을 누릅니다.
5. 사진 음영까지 반전하는 것이 적절하지 않으면 해당 그림의 `색상 반전`을 끕니다.
6. 미리보기 확인 후 PPT를 내려받습니다.

자동 영역 판단은 AI 응답에 따라 달라집니다. 특히 작은 그림과 주변 설명문이 붙어 있는 경우 확인이 필요합니다. 그림 찾기가 실패하거나 취소되어도 추출한 글자는 유지됩니다. 그림 자동 찾기는 별도 Gemini 요청이므로 사용량과 요청 횟수가 추가됩니다.

## 기존 science-lab에 적용

1. 압축을 푼 `exam-pdf-to-ppt` 폴더의 `index.html`과 **assets 폴더 전체**를 기존 `programs/exam-pdf-to-ppt/`에 덮어씁니다.
2. 기존에 사용하던 배포 절차로 배포합니다.
3. Ctrl+F5로 새로고침하고 화면의 **v23** 표시를 확인합니다.

이번에는 `assets/pdfjs/` 폴더가 반드시 필요합니다. 일부 JS 파일만 복사하면 PDF 캡처가 동작하지 않습니다. Worker의 API 경로와 인증 코드는 수정하지 않았습니다.

## 앱 전용 Cloudflare Worker에 적용

`wrangler.jsonc`의 name이 기존 앱 전용 Worker 이름인지 확인한 뒤 압축 해제 폴더에서 실행합니다.

```powershell
npm ci
npx wrangler login
npx wrangler deploy
```

이미 배포용 파일이 들어 있어 별도 빌드는 필요 없습니다. Worker는 `public-site/`를 배포하며 이 폴더에도 v23 파일을 넣었습니다. 기존 API 키와 비밀번호 Secret을 그대로 사용합니다. 처음 배포하는 경우의 Secret 설정은 `DEPLOY_PASSWORD.md`를 참고하세요.

여러 프로그램을 함께 서비스하는 Worker에는 이 프로젝트의 전용 Worker 설정을 덮어쓰지 말고 앱 폴더만 기존 구조에 맞게 적용하세요.

## 코드와 검증

- 실제 앱 코드: `assets/index-v23.js`
- 그림 처리·캡처 UI·배치: `assets/image-tools.js`
- 추가 스타일: `assets/images-v23.css`
- PDF.js 5.6.205 및 글꼴/문자표/디코더: `assets/pdfjs/` (LICENSE 포함)
- 배포 파일 갱신: `npm run build:v23`
- 자동 검사: `npm test`

원본 프로젝트의 `src/`와 `shared/`는 배포 번들보다 이전 레이아웃을 포함합니다. v23 유지보수는 위 배포 앱 코드에서 진행하세요. 기존 글자 추출 코드와의 동일성, 이미지 배치, 색상 반전, PNG의 PPT 포함 등을 포함한 22개 검사가 통과했습니다.

제공된 PDF로 실제 브라우저 렌더링, 캡처, 반전, 영역 수정, 직접 드래그 캡처, 삭제, PPT 다운로드를 확인했습니다. 이 브라우저 검사는 AI 응답을 고정 좌표로 대체하여 수행했습니다. 실제 Gemini의 자동 영역 인식 정확도와 배포 서버 연결은 이 환경에서 실호출 검증하지 않았습니다.

PDF 렌더러 공식 문서: https://mozilla.github.io/pdf.js/examples/
