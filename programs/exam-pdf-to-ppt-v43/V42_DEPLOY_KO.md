# 문항 슬라이드 스튜디오 v42

## 수정 사항

1. 기존 문항 배치, 크기, 페이지 나눔 계산을 유지합니다. PPTX 저장 마지막 단계에서 본문·표·보기 등 모든 슬라이드 텍스트 문단의 한글 단어 잘림 허용을 켭니다. PowerPoint에서 자동 줄바꿈 위치는 이 옵션에 따라 달라질 수 있습니다.
2. 편집 가능한 세로형 분수에 예시 PPT와 같은 수식의 일반 텍스트 형식을 적용합니다. 분자·분모 및 수식 제어 서식의 글꼴은 `210 M고딕 070`, 크기는 24pt입니다. 분수 주변의 일반 텍스트 서식은 유지합니다.

## 파일 사용

압축에는 빌드가 완료된 v42 파일이 포함되어 있습니다. 기존과 같은 폴더 구조로 교체하면 됩니다.

- 정적 사이트: 루트의 `index.html`과 `assets/`를 함께 교체합니다.
- Cloudflare Worker: 기존과 같이 `public-site/`를 사용합니다. 앱 파일은 `public-site/programs/exam-pdf-to-ppt/`에 있습니다.
- 소스를 다시 빌드할 때: `npm run build:v42`
- 자동 검사: `npm test`

활성 소스는 `assets/index-v42.js`와 여기서 가져오는 v42 파일입니다. `src/`는 이전 모듈 소스이므로 이번 배포본 수정에는 사용하지 않습니다. 글꼴 파일은 포함하지 않으며, PPT를 여는 컴퓨터에 `210 M고딕 070`이 설치되어 있어야 합니다.
