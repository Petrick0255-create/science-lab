# v29 코드 수정본 배포 안내

## 수정한 원인과 동작

- **밑줄 누락:** 텍스트 인식 결과만으로 서식을 결정하던 부분을 보완했습니다. PDF의 실제 선과 글자 위치를 대조해 본문과 표 셀에 밑줄을 적용하고, PPT에도 편집 가능한 밑줄 서식으로 내보냅니다. 표 테두리·빈칸 상자·분수선은 구분합니다.
- **㉠·㉡ 상자 오인:** 기호만 담긴 얇은 빈칸 상자를 별도 그림으로 캡처하던 경우를 제외했습니다. 이번 자료에서는 실제 표 객체 오인보다 그림 캡처 오인이 원인이었습니다. 본문의 기호는 유지합니다.
- **표와 그림 중복:** 표 셀 경계를 이용해 그림과 격자선을 분리하고, 주변 셀 글자를 그림으로 중복 캡처하지 않도록 수정했습니다. 표 안 그림의 여백도 셀 안으로 제한합니다.
- **기호·분수 누락:** 글자 대신 작은 이미지로 저장된 원·네모·세모를 주변 문맥과 연결해 보정합니다. 표 셀 안의 분수는 분자와 분모를 구분해 편집 가능한 `(분자)/(분모)`로 유지합니다.
- **내용 겹침:** 긴 본문과 여러 표를 두 장에 강제로 배치하던 제한을 제거했습니다. 필요한 만큼 페이지를 나누고, 표로 시작하는 이어지는 페이지에도 번호 공간을 확보합니다. 긴 조건 문장도 줄바꿈합니다.

특정 문항 번호나 PDF 좌표를 고정한 수정이 아닙니다. 기존 본문 전사 지시문과 파서, 번호 스타일·번 선택·2pt 간격 크기, 색상 반전과 고해상도 캡처, 실제 표와 2.25pt 테두리를 유지했습니다. 화면에 v29가 표시됩니다.

## 배포

1. ZIP을 새 폴더에 압축 해제합니다.
2. `exam-pdf-to-ppt` 폴더에서 터미널을 엽니다.
3. 기존 Worker를 관리하는 Cloudflare 계정으로 아래 명령을 실행합니다.

```powershell
npm ci
npx wrangler deploy
```

배포 파일은 `public-site`에 이미 준비되어 있습니다. 포함된 설정은 현재 Worker인 `exam-pdf-to-ppt-secure`를 대상으로 합니다. 기존 Worker의 서버 비밀값은 다시 입력할 필요가 없습니다. ZIP에는 API 키나 공용 비밀번호를 넣지 않았습니다.

기존 프로젝트에서 배포한다면 `public-site/programs/exam-pdf-to-ppt` 폴더 전체를 교체한 뒤 기존 배포 방법을 사용하세요. 다른 앱을 함께 운영하는 설정은 유지하세요.

배포 후 Ctrl+F5로 새로고침해 **v29**를 확인하고 PDF를 **다시 분석**하세요. 이미 받은 PPT는 자동으로 변경되지 않습니다. 이번 작업에서는 운영 사이트에 직접 배포하지 않았습니다.

소스를 추가 수정할 때는 `npm run build:v29`를 사용하세요. `assets/index-v29.js`와 v29 보조 모듈이 활성 소스이며, 이전 `src`용 `npm run build`는 이번 배포본을 만드는 명령이 아닙니다.

## 검증 범위

제공한 통합과학 PDF와 기존 PPT를 비교했습니다. 실제 분석 서버 응답을 받은 뒤 같은 응답으로 수정된 코드의 25문항 미리보기와 PPT 내보내기를 재검증했습니다. 본문·표 밑줄, 4·9·23번 기호 상자 제외, 12번 기호, 14번 분수, 19·24번 표 안 그림, 23번 페이지 나눔을 확인했습니다. 실제 표는 10개입니다.

이전 화학 3H1610.pdf의 표 7개와 내보내기, 생명과학 3S1603.pdf의 그림 검출도 재실행했습니다. 회귀 검사 50개가 통과했습니다. PPT는 내부 구조와 서식을 검사했으며 PowerPoint 프로그램 자체의 화면 렌더링을 확인한 것은 아닙니다.

글자 위치 정보가 없는 스캔 PDF, 선이 없는 표, 복잡한 기호는 자동 보정 범위가 제한됩니다. AI 전사 결과와 설치 글꼴에 따라서도 차이가 생길 수 있으므로 변환 결과를 미리보기에서 확인하세요.
