# v28 배포 안내

## 수정 사항
- 한 표의 셀 누락 때문에 모든 표를 버리던 오류를 수정했습니다.
- 표의 행·열, 병합 셀, 열 너비와 행 높이를 유지하고 실제 PowerPoint 표로 넣습니다. 테두리는 2.25pt입니다.
- 인식한 셀을 보존하고 누락되거나 내용이 크게 잘린 셀만 한 번 더 요청합니다. 그래도 확인이 필요한 셀은 편집 화면에 갈색으로 표시합니다.
- 그림 아래 한글 이름표와 독립된 (가)/(나) 위의 글자형 화학식을 함께 캡처합니다. 문제별 고정 좌표를 사용하지 않습니다.
- 표 안의 그림은 해당 표의 위치에 넣고 가로세로 비율을 유지합니다.
- 기존 본문 전사 지시문과 파서, 번호 옵션, 선명한 캡처 설정을 유지했습니다.

## 현재 Worker에 배포하기
1. ZIP을 새 폴더에 압축 해제합니다.
2. 압축 안의 exam-pdf-to-ppt 폴더에서 터미널을 엽니다.
3. 아래 명령을 순서대로 실행합니다.

    npm ci
    npx wrangler deploy

현재 사용 중인 Worker 이름은 exam-pdf-to-ppt-secure이고, 압축에 포함된 wrangler.jsonc도 같은 이름입니다. 기존 Cloudflare 계정으로 로그인되어 있어야 합니다. 배포 파일은 public-site 폴더에 이미 빌드되어 있습니다. 기존 Worker의 API 키·비밀번호 등 서버 비밀값은 다시 입력할 필요가 없습니다. 비밀값은 ZIP에 포함하지 않았습니다.

기존 프로젝트에서 배포한다면 public-site/programs/exam-pdf-to-ppt 폴더 전체를 교체한 뒤 기존 방식으로 배포하세요. 여러 앱을 함께 운영하는 설정 파일은 그대로 사용하세요.

배포 후 Ctrl+F5로 새로고침하여 화면의 v28 표시를 확인하고 PDF를 다시 분석하세요. 기존 PPT 파일에는 자동 반영되지 않습니다.

소스를 추가 수정할 때만 npm run build:v28을 실행하세요. 이전 src 폴더용 npm run build는 이번 배포본을 생성하는 명령이 아닙니다.

## 검증
3H1610.pdf를 실제 분석 서버로 처리했습니다. 9·11·12·16·17·18·20번의 표 7개, 기준 셀 101개의 응답을 확인했고 누락 표시가 남지 않았습니다. 12번 분수의 분자·분모, 16번 표 속 그림, 20번 병합 셀을 원본과 대조했습니다. 미리보기와 PPT 다운로드를 검증했고, PPT 내부의 실제 표 7개·표 속 그림 2개·2.25pt 테두리를 확인했습니다.

그림 검출은 이전 화학 3H1706.pdf와 생명과학 3S1603.pdf에도 다시 실행했습니다. 본문 보존, 문항 경계, 셀 누락 처리 등 자동 검사 43개가 통과했습니다.

## 확인이 필요한 경우
AI 인식은 PDF마다 달라질 수 있으므로 셀 내용은 원본과 대조하세요. 분수는 편집 가능한 (분자)/(분모) 텍스트로 들어갑니다. 선이 없는 표나 스캔 이미지뿐인 표는 구조 자동 탐지가 제한됩니다. 원본 그림 자체의 낮은 해상도를 복원하지는 않습니다. 미리보기는 브라우저 기준이며 PowerPoint 글꼴에 따라 배치가 조금 달라질 수 있습니다.
