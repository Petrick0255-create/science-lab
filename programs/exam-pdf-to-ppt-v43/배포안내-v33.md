# v33 배포 안내

문장·자료의 항목 표시로 쓰인 큰 동그라미(○, ◯, ◦)를 작은 점(•)으로 표시하도록 수정했습니다. 문장 처음, 줄 처음, 문장 끝 다음, [준비물] 같은 제목 다음의 항목 표시를 처리합니다. ㉠·㉡, 원소 모형의 ○·■·▲, 문장 안에서 의미를 가진 원 기호는 그대로 유지합니다. 미리보기와 PPT 내보내기에 같은 규칙을 적용합니다.

이전 분수·그림 밝기·발문 우선 배치 수정도 포함합니다. 자동 검사 58개가 통과했습니다.

ZIP을 새 폴더에 풀고 exam-pdf-to-ppt 폴더에서 실행하세요.

```powershell
npm.cmd ci
npx.cmd wrangler login
npx.cmd wrangler deploy
```

이미 로그인되어 있으면 login은 생략할 수 있습니다. 배포 후 Ctrl+F5로 새로고침해 v33을 확인하고 PDF를 다시 분석하세요. 운영 사이트에 직접 배포하지 않았습니다. 추가 소스 수정 후 빌드는 `npm.cmd run build:v33`입니다.
