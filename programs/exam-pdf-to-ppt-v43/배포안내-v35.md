# v35 배포 안내

v34에서 기호 박스를 배치하며 본문을 여러 개의 텍스트 상자로 나누던 문제를 수정했습니다. 이제 박스가 포함된 본문 블록도 하나의 편집 가능한 텍스트 상자로 내보냅니다. ㉠·㉡ 박스만 2.25pt 테두리와 가운데 정렬을 가진 별도 도형으로 남습니다.

기호 박스 공간은 본문의 탭으로 확보합니다. PPT에서 본문 길이·글꼴·줄바꿈을 크게 변경하면 별도 도형인 박스 위치는 함께 조정해야 합니다. 그림 아래 (가)/(나) 텍스트 상자, 세로 분수, 작은 점, 그림 밝기 보정은 유지했습니다.

## 배포

ZIP을 새 폴더에 풀고 exam-pdf-to-ppt 폴더에서 실행하세요.

```powershell
npm.cmd ci
npx.cmd wrangler login
npx.cmd wrangler deploy
```

이미 로그인했다면 login은 생략할 수 있습니다. 배포 후 Ctrl+F5 → v35 확인 → PDF 다시 분석하세요. 기존에 내려받은 PPT에는 자동 반영되지 않습니다. 운영 사이트에 직접 배포하지 않았습니다.

추가 코드 수정 후에는 `npm.cmd run build:v35`를 사용하세요.

## 검증

자동 검사 62개가 통과했습니다. 통합과학 PDF의 25문항 미리보기와 내보내기를 재검증했고, 생성된 테스트 PPT를 실제 PowerPoint에서 열어 4번 본문 텍스트 상자 1개와 기호 박스 2개를 확인했습니다. 사용자 원본 PPT는 수정하지 않았습니다.
