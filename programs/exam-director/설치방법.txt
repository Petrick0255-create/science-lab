모의고사 문제 관리 페이지 설치
================================

이미 만들어진 관리 시트
https://docs.google.com/spreadsheets/d/1LvDHhARksHVu4j2FWTR_YuGDlVJcnTZFS2UeBlbSt08/edit

문제 이미지 저장 폴더
https://drive.google.com/drive/folders/1IQohwxwwiT6-BSvVDe6WEZWu070FdYlU

1. Apps Script 연결
-------------------
1) 위 관리 시트를 엽니다.
2) 확장 프로그램 > Apps Script를 엽니다.
3) 기본 Code.gs 내용을 모두 지우고 ZIP 안의 Code.gs 전체를 붙여넣습니다.
4) 저장한 뒤 setupMockExamManager 함수를 한 번 실행하고 권한을 허용합니다.
5) 시트로 돌아가 새로고침합니다.
6) 상단의 '모의고사 관리 > 동기화 키 설정'에서 원하는 키를 만듭니다.

2. 웹 앱 배포
-------------
1) Apps Script 오른쪽 위 '배포 > 새 배포'를 누릅니다.
2) 유형은 '웹 앱', 실행 사용자는 '나', 액세스 사용자는 '모든 사용자'로 설정합니다.
3) 배포 후 /exec 로 끝나는 웹 앱 URL을 복사합니다.

3. 페이지 연결
-------------
1) index.html을 실행합니다. 로컬 파일로 열어도 되고 GitHub Pages에 올려도 됩니다.
2) 오른쪽 위 '연결 설정'을 누릅니다.
3) Apps Script 배포 URL과 앞에서 만든 동기화 키를 입력합니다.
4) 연결되면 시트의 기존 문항 정보를 자동으로 불러옵니다.

사용 흐름
---------
- 기록: 모의고사 제목·유형·번호·배점·난이도·정답·해설을 입력합니다. 이미지는 선택 사항입니다.
- 제목: 한 번 사용한 모의고사 제목은 드롭다운에서 다시 선택합니다.
- 저장: 브라우저 IndexedDB에 먼저 저장되고, 연결된 상태라면 곧바로 시트와 Drive에 동기화됩니다.
- 비교: 모의고사를 최대 8개 선택해 유형별 이미지 미리보기로 나란히 비교합니다. 각 문항 카드에서 비교 메모를 바로 저장할 수 있습니다.
- 분석: 모의고사별 정답 번호·배점·난이도·유형 분포를 표시합니다.
- 빠른 분석: HWP 파일에서 01번부터 문항 머리말을 찾아 번호·동그라미 정답·배점·유형만 추출하고, 번호별 유형 배치표로 표시합니다.

해설 위첨자·아래첨자
---------------------
해설 칸은 한글 문서에서 붙여넣은 <sup>/<sub> 또는 vertical-align 서식을 보존합니다.
시트에는 다시 편집할 수 있는 '해설 HTML'과 검색용 '해설 텍스트'가 함께 저장됩니다.

주의
----
- Apps Script 코드를 수정한 뒤에는 '배포 관리 > 수정 > 새 버전'으로 다시 배포해야 합니다.
- 웹페이지에서 동기화하면 기존 시트 데이터는 먼저 '백업' 시트에 JSON 조각으로 보관됩니다.
- Google Sheets 셀 글자 수 제한을 피하기 위해 백업 JSON은 여러 행으로 나뉩니다.
