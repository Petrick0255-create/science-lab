미리보기

    저장한 그림에는 편집 도구와 작업 이름이 포함되지 않습니다. 예시 데이터는 합성값이며, 글꼴은 기기의 명조·고딕 글꼴을 사용합니다.

    Claude에서 사용하기

    한 번 연결하면 Claude가 그래프 설정을 만들고, 검사하고, SVG와 편집 링크를 돌려줄 수 있습니다. 그래프 처리에는 별도 AI API를 호출하지 않습니다.

    웹 · 데스크톱

    Claude의 맞춤 설정 → 커넥터 → 맞춤 커넥터 추가에서 아래 주소를 입력하고, 인증은 ‘로그인 없음’을 선택하세요.

    Claude Code

    같은 원격 도구를 연결하거나, 프로젝트의 명령 도구로 작업 파일을 SVG로 변환할 수 있습니다.

    도구 연결이 어려울 때

    아래 안내를 Claude에 전달하세요. 생성한 JSON을 ‘작업 파일 열기’나 ‘그래프 설정’으로 불러오면 됩니다.

    안내 파일 받기

    사용자가 연결을 허용한 도구 안에서 Claude가 방식을 선택합니다. 연결 자체를 Claude가 자동 승인할 수는 없습니다. 원격 요청은 이 사이트에서 처리하며, 그래프 파일을 서버에 보관하지 않습니다. 편집 링크에는 전체 그래프 설정이 들어갑니다.
