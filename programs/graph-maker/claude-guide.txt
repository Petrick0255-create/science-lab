J&B LAB 과학 문항 그래프 제작 도구

이 도구는 과학 문항용 흑백 그래프를 좌표와 설정으로 정확하게 그립니다.
페이지: https://science-lab1.parkjunbum0255.workers.dev/programs/graph-maker/
원격 MCP: https://science-lab1.parkjunbum0255.workers.dev/programs/graph-maker/mcp
전체 규격: https://science-lab1.parkjunbum0255.workers.dev/programs/graph-maker/graph-schema.json

사용 환경에서 가능한 방법을 선택합니다.
1. 이미 원격 MCP 도구가 연결되어 있으면 get_graph_guide → render_graph 순서로 사용합니다.
   validate_graph는 설정의 구조, 범위, 추세선 계산을 검사하는 도구입니다.
2. Claude Code에서는 다음 명령으로 같은 원격 도구를 연결할 수 있습니다.
   claude mcp add --transport http science-graph https://science-lab1.parkjunbum0255.workers.dev/programs/graph-maker/mcp
   로컬 저장소가 있으면 다음 명령으로 SVG를 만들 수도 있습니다.
   node programs/graph-maker/graph-cli.mjs input.json output.svg
   로컬 MCP가 필요하면 node programs/graph-maker/graph-cli.mjs --stdio 를 사용합니다.
3. 도구를 사용할 수 없으면 아래 규격에 맞는 JSON 파일을 사용자에게 제공합니다.
   사용자는 사이트에서 '작업 파일 열기' 또는 '그래프 설정 · JSON'으로 불러옵니다.
4. 도구 접근 권한이 없는데 연결되었다고 말하지 않습니다. 연결·승인은 사용자가 합니다.

제작 원칙
- 명조 계열의 흑백 선화를 기본으로 하고, 자료를 구분할 때 선 모양과 점 모양을 이용합니다.
- 숫자, 단위, 축 범위는 사용자 자료를 보존합니다. 이미지로부터 판독이 불확실한 숫자는 추정이라고 명시합니다.
- 서로 다른 물리량에는 각각의 y축을 지정합니다. series.axis는 0부터 시작하는 세로축 번호입니다.
- 곡선이나 시계열도 points 배열로 표현합니다. 좌표를 자동으로 매끈하게 바꾸지 않습니다.
- 산점도에 trend:true를 사용하면 입력한 좌표로 실제 최소제곱 추세선을 계산합니다. 인과관계를 의미하지는 않습니다.
  여러 자료를 합친 추세선은 합친 좌표로 marker:"hidden", trend:true인 자료를 하나 더 만듭니다(점은 그리지 않음).
- 한글 등 문서에 넣을 크기가 정해져 있으면 print:{"widthMm":65, "textPt":9}처럼 지정합니다.
  fontSize가 자동으로 계산되고, 결과의 print에 문서에서의 실제 글자 크기(pt)가 나옵니다.
  범례·단위 글자까지 같은 크기로 하려면 print.subPt 또는 subFontSize를 함께 지정합니다.
- 가로축 마지막 눈금을 최댓값에 두어도 눈금 글자가 잘리지 않도록 여백을 자동으로 잡습니다.
- 글자 표시, 기준선 이름, 범례가 선·점과 겹치면 경고가 나옵니다. 경고가 없어질 때까지 위치를 옮깁니다.
- 설명용 예시는 합성 데이터입니다. 관측 자료나 기출 원본의 정확한 값이라고 주장하지 않습니다.
- 불필요한 격자·눈금·범례는 제거하고, 필요한 지점과 구간만 표시합니다.
- break:true는 원점과 양의 축 최솟값 사이의 생략 표시입니다. 축 중간의 임의 범위를 생략하는 기능은 아닙니다.
- t_1, m^{2}, μg/m^{3} 같은 첨자 표기를 지원합니다. HTML이나 실행 코드를 넣지 않습니다.
- 서로 다른 두 그래프는 panels에 담습니다. 패널은 최대 3개, 세로축은 패널마다 최대 3개입니다.
- 그림을 수정할 때 원래 spec의 좌표·단위·축 연결을 유지하며 필요한 필드만 바꿉니다.
- SVG와 편집 링크를 제공하고, 후속 편집을 위해 원래 JSON 파일도 제공합니다.
- 큰 자료는 링크보다 파일로 전달합니다. 작업 파일은 250 KB 이내입니다.

예시 종류
paired: 두 해 비교, 월·주차 묶음 눈금, 이중축
weather: 기온·기압·상대 습도, 세 축, A·B 구간
negative: 산점도와 음의 상관 추세선
anomaly: 불규칙 시계열과 A·B 지점
particles: 두 지역의 꺾은선, 사각형·원 점, 격자
solar-scatter: 산점도, 축 생략, 양의 상관 추세선
seasonal: 반복 계절 음영, 이중축, 첨자
mechanics: 기호 눈금, 구간별 운동
impulse: 힘·시간 곡선과 면적 음영

최소 작업 파일 예시
{
  "version": 1,
  "title": "시간에 따른 속도",
  "description": "설명용 데이터",
  "width": 820,
  "height": 520,
  "fontSize": 18,
  "panels": [{
    "frame": "arrows",
    "x": {"label":"시간", "unit":"s", "min":0, "max":5, "ticks":[0, {"value":1,"label":"t_1"}, {"value":3,"label":"t_2"}]},
    "y": [{"label":"속도", "unit":"m/s", "min":-2, "max":4, "ticks":[-2,0,2,4]}],
    "series": [{"name":"", "points":[[0,0],[1,3],[3,3],[5,-1]], "line":"solid"}],
    "annotations": [{"type":"vline", "x":1, "label":"A"}],
    "legend":"none"
  }]
}

세부 자료 정의
- x/y축: min, max, label, unit, ticks. ticks는 숫자 또는 {value,label} 배열입니다.
- x.groups: {from,to,label} 배열. 월별 주차처럼 묶음 눈금을 표시합니다.
- series: points, name, axis, type(line/scatter), line(solid/dash/dashdot/dot), marker(none/circle/square/open/hidden), color(#111111/#555555/#888888/#aaaaaa), width, size, trend, trendLabel, trendLine, fill.
  marker: none은 꺾은선에서 점 없음, 산점도에서는 원. hidden은 점을 그리지 않습니다.
- bands: {from,to,shade,label,legendLabel} 배열. legendLabel을 지정하면 같은 이름을 한 번만 범례에 표시합니다. shade는 0.02~0.4의 회색 농도입니다.
- annotations: type(vline/hline/text/range), x,y,to,axis,label,dx,dy,leader,arrow,labelPos.
  vline: x 지점 점선과 위쪽 이름. hline: y 값 점선(labelPos: right-above/right-below/left-above/left-below). range: x~to 위쪽 구간 괄호.
  text: (x,y)의 이름을 dx,dy만큼 옮겨 표시. leader:true이면 지시선을 연결합니다.
- legend: none/top-left/top-right/bottom-right/above.
- grid: none/major/dense. frame: box/arrows.
- 그림 전체: width, height, fontSize, font(serif/sans), subFontSize(범례·단위 글자), print{widthMm,textPt,subPt}.

처리 범위와 저장
브라우저에서는 기기 안에서 그래프를 그립니다. 원격 MCP·API 요청은 Cloudflare에서 처리합니다.
별도 AI API는 사용하지 않으며, 그래프 작업 파일을 서버의 데이터베이스에 보관하지 않습니다.
브라우저의 마지막 작업은 해당 브라우저에 저장됩니다. 편집 링크에는 전체 그래프 설정이 포함됩니다.
설정 검사는 수치 범위와 렌더링 가능성을 확인하며 과학적 단위·실험 설계·정답의 타당성을 보증하지 않습니다.
