# v34 배포 안내

## 추가한 기능

- 원본 PDF에서 사각형 안에 있는 ㉠·㉡ 등의 기호를 문맥과 함께 찾아 표시합니다. PPT에서는 흰색 2.25pt 테두리, 검정 채움, 가로·세로 가운데 정렬의 편집 가능한 텍스트 상자로 만듭니다. 같은 기호가 보기에서 다시 나오더라도 원본에 박스가 없으면 박스를 붙이지 않습니다.
- 그림 아래의 (가), (나) 같은 이름표는 캡처에서 분리하여 그림 아래에 편집 가능한 텍스트 상자로 넣습니다. 괄호와 글자가 PDF에서 따로 저장된 경우도 처리합니다. 나란한 그림의 이름표는 같은 높이에 놓습니다.
- 한 이미지 안에 여러 그림이 함께 있으면 원래 상대 위치를 유지하면서 각각의 이름표를 별도 텍스트로 배치합니다. 그림을 임의의 좌표로 잘라 나누지는 않습니다.
- 기존 작은 점 표시, 분수, 검은 배경을 유지하는 그림 밝기 보정, 발문 우선 배치 기능을 유지합니다.

## 배포

ZIP을 새 폴더에 풀고 exam-pdf-to-ppt 폴더 안에서 실행하세요.

```powershell
npm.cmd ci
npx.cmd wrangler login
npx.cmd wrangler deploy
```

이미 로그인했다면 login은 생략할 수 있습니다. 배포 후 Ctrl+F5 → **v34** 확인 → PDF 다시 분석하세요. 기존 PPT는 자동 변경되지 않습니다. 운영 사이트에 직접 배포하지 않았습니다.

추가 소스 수정 후에는 `npm.cmd run build:v34`를 사용합니다.

## 검증

자동 검사 61개 통과. 제공한 통합과학 PDF에서 4·9번의 기호 박스 4개와 그림 이름표 8개를 확인했습니다. 생성된 테스트 PPT를 실제 PowerPoint에서 읽기 전용으로 열고 렌더링해 4번 기호 박스와 8번 그림 아래 이름표를 확인했습니다. 사용자 원본 PPT는 수정하지 않았습니다.

문자와 선 정보가 없는 스캔 PDF 또는 이름표가 그림 픽셀에 완전히 포함된 경우에는 자동 분리가 제한됩니다. 문항별 고정 좌표를 사용하지 않습니다.
