# v31 배포 안내

## 변경 사항

- `1/299 792 458`, `1/10 000 000`, `(분자)/(분모)`처럼 읽힌 분수를 분자·분모와 가로 분수선으로 표시합니다. 빨간 가로형 표시는 적용하지 않습니다.
- 웹앱 미리보기와 PPT 내보내기에 반영합니다. PPT는 편집 가능한 Office 수식으로 저장합니다. 표의 나머지 셀도 기존처럼 편집할 수 있습니다.
- 일반 캡처 그림과 표 안 그림 모두 PowerPoint의 밝기 +40%, 대비 0%로 저장합니다. 캡처 원본 픽셀을 덮어쓰지 않아 PowerPoint에서 밝기를 다시 조정할 수 있습니다. 색상 반전은 유지됩니다.
- 웹 미리보기의 밝기는 근사 표시입니다. 밝기를 올리면 검은 배경도 밝아질 수 있습니다.
- 발문 우선 배치와 번호 옵션, 밑줄, 표 테두리 2.25pt를 유지합니다.

## 배포

ZIP을 새 폴더에 풀고 `exam-pdf-to-ppt` 폴더 안에서 실행하세요.

```powershell
npm.cmd ci
npx.cmd wrangler login
npx.cmd wrangler deploy
```

이미 로그인되어 있으면 login은 생략할 수 있습니다. 배포 파일은 public-site에 빌드되어 있습니다. 기존 Worker 설정과 서버 비밀값을 사용합니다. 배포 후 Ctrl+F5로 새로고침해 **v31**을 확인하고 PDF를 다시 분석하세요. 기존 PPT는 바뀌지 않습니다. 운영 사이트에 직접 배포하지 않았습니다.

코드를 추가 수정할 때는 `npm.cmd run build:v31`을 사용하세요.

## 검증과 범위

자동 검사 53개가 통과했습니다. 제공한 통합과학 PDF와 저장된 실제 서버 응답으로 25문항 미리보기 및 내보내기를 확인했습니다. 생성된 PPT 내부에서 편집 가능한 분수 수식 3개와 캡처 그림 31개 모두에 밝기 +40%가 적용된 것을 검사했습니다. PowerPoint 프로그램 자체에서 열어 렌더링한 검증은 수행하지 않았습니다.

숫자 분수와 괄호로 구분된 분자·분모를 변환합니다. 중첩 분수나 복잡한 수식까지 모두 인식하는 수식 OCR 기능은 아닙니다. `/`가 있는 숫자 표현도 분수로 처리하므로 날짜 등의 표현은 확인이 필요합니다. 이미지 안의 글자는 이미지 그대로입니다.

구현 형식은 Microsoft의 [Office 수식 규격](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-odrawxml/cdafda97-9124-48ed-8d64-7f1dd9197c8a)과 [그림 밝기 속성](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.luminanceeffect.brightness?view=openxml-3.0.1)을 사용합니다.
