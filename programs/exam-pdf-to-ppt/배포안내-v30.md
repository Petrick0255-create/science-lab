# v30 배포 안내

발문·설명문을 먼저 배치하고 표를 그 아래에 배치하도록 웹앱 코드를 수정했습니다. 분석 결과에서 표가 발문 앞이나 중간에 반환되어도 발문 위치를 먼저 확보합니다. 표가 남은 공간에 들어가지 않으면 표를 다음 장으로 넘깁니다. 미리보기와 PPT 내보내기에 같은 규칙을 적용합니다.

번호 옵션, 밑줄, 그림, 실제 편집 가능한 표, 2.25pt 테두리는 유지했습니다. 화면에는 v30이 표시됩니다.

## 배포 방법

1. ZIP을 새 폴더에 압축 해제합니다.
2. `exam-pdf-to-ppt` 폴더에서 터미널을 엽니다.
3. 현재 Worker를 관리하는 Cloudflare 계정으로 실행합니다.

```powershell
npm ci
npx wrangler deploy
```

배포 파일은 `public-site`에 빌드되어 있습니다. 포함된 설정은 기존 `exam-pdf-to-ppt-secure` Worker를 대상으로 합니다. 기존 프로젝트에서 배포한다면 `public-site/programs/exam-pdf-to-ppt` 폴더 전체를 교체하고 기존 배포 방법을 사용하세요.

배포 후 Ctrl+F5로 새로고침해 **v30**을 확인하고 PDF를 다시 분석하세요. 기존 PPT는 자동으로 바뀌지 않습니다. 운영 사이트에 직접 배포하지는 않았습니다.

추가 코드 수정 후에는 `npm run build:v30`을 사용하세요. 활성 소스는 `assets/index-v30.js`와 v30 보조 모듈입니다.

## 검증

표가 발문 앞에 있는 경우, 설명 중간에 있는 경우, 큰 표가 다음 장으로 넘어가는 경우에 발문의 위치가 표 없는 경우와 동일한지 검사했습니다. 자동 검사 52개가 통과했습니다. 제공한 통합과학 PDF와 기존 서버 응답으로 25문항의 미리보기와 PPT 내보내기도 재검증했습니다.
