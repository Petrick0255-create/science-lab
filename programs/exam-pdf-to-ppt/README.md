# 문항 슬라이드 스튜디오

20문항 또는 25문항 모의고사 PDF를 Gemini로 읽고, 본문과 첨자를 수정한 뒤 편집 가능한 PowerPoint 파일을 만드는 웹앱입니다. GitHub에 올릴 수 있는 소스 프로젝트이며, 자동으로 배포되지는 않습니다.

## 적용 규칙

| 항목 | 출력 |
| --- | --- |
| 슬라이드 | 4:3, 10 × 7.5인치, 검은 배경 |
| 기본 글꼴 | `210 M고딕 070` (첨부 PPT의 실제 패밀리 이름) |
| 본문 | 흰색 24pt, 자동 글자 축소 없음 |
| 번호 스타일 1 | 노란색 `FFFF00`, 28pt, 독립 텍스트 상자 |
| 번호 스타일 2 | 흰색 `FFFFFF`, 40pt, 독립 텍스트 상자, `1번` 형식 |
| 위·아래첨자 | 실제 PowerPoint 첨자 서식, 18pt 보조 글자 |
| 긴 문항 | 내용 순서를 유지하며 이어지는 슬라이드로 분할 |

본문은 줄마다 편집 가능한 텍스트 상자로 만들어집니다. 20/25문항은 시험의 문항 수이며 슬라이드 수와 같다는 뜻은 아닙니다. 텍스트가 긴 문항은 여러 장으로 나뉩니다. 분할 페이지 정보와 검토 메모는 발표자 노트에 저장됩니다.

## 실행 준비

Node.js 22.12 이상이 필요합니다. 프로젝트 루트(`package.json`이 있는 폴더)에서 실행하세요.

```bash
npm ci
```

`.env.example`을 `.env`라는 이름으로 복사하고, 승인된 서버용 Gemini API 키를 `GEMINI_API_KEY`에 설정합니다. 키는 브라우저에서 받지 않습니다. 예시 키 문자열을 그대로 사용하면 분석이 실패합니다.

Windows PowerShell에서는 복사할 때 다음 명령을 사용할 수 있습니다.

```powershell
Copy-Item .env.example .env
```

macOS/Linux에서는 다음과 같습니다.

```bash
cp .env.example .env
```

개발 모드:

```bash
npm run dev
```

브라우저에서 [로컬 앱](http://127.0.0.1:5173)을 엽니다. 개발 모드 API 포트는 8787이며 `vite.config.js`의 프록시 주소와 일치해야 합니다.

실행용 빌드:

```bash
npm run build
npm start
```

빌드 후에는 [서버 앱](http://127.0.0.1:8787)으로 접속합니다. GitHub Pages는 정적 호스팅이므로 이 서버 앱을 단독으로 실행할 수 없습니다. Firebase 전용 설정은 포함하지 않았습니다.

## 사용 순서

1. PDF 한 개를 선택하거나 끌어다 놓습니다. 클립보드가 PDF 파일 데이터를 제공하는 환경에서는 붙여넣기도 지원합니다.
2. 20문항 또는 25문항을 선택하고 분석합니다. 앱의 업로드 한도는 10MB입니다.
3. 문항 번호, 질문·제시문·보기·선택지를 원본 PDF와 대조합니다. `원본 PDF 보기`로 해당 쪽을 확인할 수 있습니다.
4. 누락·중복·범위 밖 번호를 수정합니다. 필요한 경우 문항이나 본문을 추가합니다. 번호가 1~20 또는 1~25로 완전해야 내보낼 수 있습니다. 번호가 완전하더라도 내용이 정확하다는 보장은 아닙니다.
5. 첨자로 만들 글자를 선택하고 `위첨자` 또는 `아래첨자` 버튼을 누릅니다. 선택지가 본문에 중복되어 있지 않은지도 확인합니다.
6. 번호 스타일을 선택하고 PPTX를 내려받습니다.

편집 내용은 메모리에만 있습니다. 새로고침·탭 종료 시 사라지며, 새 PDF 선택이나 재분석 시 교체 확인을 요청합니다.

## 위첨자·아래첨자

편집기에 보이는 다음 표기를 실제 서식으로 변환합니다. HTML을 실행하지 않고 지원 태그만 해석합니다.

| 편집기 입력 | 의미 |
| --- | --- |
| `H<sub>2</sub>O` | H₂O |
| `x<sup>2</sup>` | x² |
| `v<sub>0</sub>` | v₀ |
| `SO<sub>4</sub><sup>2−</sup>` | SO₄²⁻ |
| `<u>강조</u>` | 밑줄 |

일반적인 유니코드 첨자(`₂`, `²`, `⁺`, `₀` 등)도 실제 서식으로 변환합니다. 위·아래첨자 태그를 서로 중첩할 수는 없습니다. 핵종의 좌측 질량수·원자번호 동시 정렬, 세로 분수, 근호, 행렬 등 복잡한 수식은 완전한 Office 수식 객체(OMML)로 재구성하지 않습니다. 원문 대조 후 보완이 필요합니다.

## 글꼴과 레이아웃 주의

`210 M고딕 070` 글꼴 파일은 재배포하거나 PPT에 임베드하지 않습니다. 정당한 사용 권한을 갖춘 글꼴을 **PPT를 열 PC**에 설치해야 지정 서식대로 보입니다. 미설치 환경에서는 대체 글꼴이 사용됩니다. 화면 미리보기 역시 설치 글꼴에 따라 달라집니다.

PPT의 공통 글꼴·색·번호·크기 규칙을 적용한 텍스트 중심 재배치이며, 참고 PPT의 모든 배경 그림·로고·개별 위치를 그대로 복제하는 템플릿 엔진은 아닙니다. 단순 표는 텍스트로 전사하고 원본 표 격자를 재구성하지 않습니다. 그림·그래프·그림 선택지는 위치 표시와 보충 메모를 남기며 이미지를 자동 삽입하지 않습니다.

## API와 안전장치

- 서버는 `@google/genai`를 통해 PDF와 추출 지시를 전송합니다. JSON 스키마, 종료 사유, 데이터 형식과 문항 번호를 검사합니다.
- PDF 지시문을 실행하지 않도록 전사 데이터와 시스템 지시를 분리합니다. 임의 정답 생성과 내용 추측을 금지합니다.
- 실제 문항이 누락되면 임의 문항으로 채우지 않습니다. 화면에서 검토하게 합니다.
- API 키·접속 암호·업로드 PDF·원문 모델 응답은 로그로 출력하지 않습니다. 원격 오류의 내부 URL이나 원문을 브라우저에 노출하지 않습니다.
- PDF는 요청 처리 중 서버 메모리에만 존재합니다. Google 측 보관·사용 정책은 별개입니다. 이용 권한이 있는 자료만 처리하세요.
- 기본 서버는 `127.0.0.1`에만 연결됩니다. 외부 접속을 위해 `HOST=0.0.0.0`으로 바꾸면 `APP_PASSWORD`가 필수입니다. HTTPS와 적절한 접근 제한이 있는 서버 환경에서만 외부에 제공하세요.
- 앱 접속 암호는 브라우저 메모리에만 보관하며 저장소에 저장하지 않습니다. 공유 암호는 사내 소규모 사용을 위한 최소 보호이며 사용자별 권한 관리나 완전한 운영 인증 체계를 대신하지 않습니다.
- 한 프로세스에서 동시에 한 건만 분석하고 요청 간격을 제한합니다. 분석 시간 제한과 취소를 지원합니다. 취소해도 이미 발생한 API 비용이 취소된다는 뜻은 아닙니다.
- `GEMINI_MODEL`은 서버 환경변수입니다. 기본값은 기존 프로젝트의 `gemini-2.5-flash`이며, 운영 계정에서 사용 가능한 PDF·구조화 출력 지원 모델로 변경할 수 있습니다. 모델 제공 여부와 한도는 운영 시 확인하세요.

공식 참고: [Gemini PDF 처리](https://ai.google.dev/gemini-api/docs/document-processing), [구조화 출력](https://ai.google.dev/gemini-api/docs/structured-output).

## 검증

```bash
npm run check
```

자동 테스트는 첨자 파싱, 유니코드 변환, 20/25문항 누락·중복 검사, 긴 문항의 무손실 분할, 실제 PPTX XML의 글꼴·크기·첨자 baseline, 잘린 JSON 거부, API 오류·암호 보호·다운로드 경로를 확인합니다. GitHub Actions에서도 같은 검사를 실행합니다.

**실제 Gemini API 키가 제공되지 않아 실 API 전사 품질은 검증하지 않았습니다.** API 경로 테스트는 명시적인 테스트용 응답을 사용하며 비용이 발생하지 않습니다. 첨부된 6쪽 25문항 PDF는 로컬에서 구조와 수식 표기 특성을 분석했습니다. 최종 PowerPoint 설치 환경에서의 글꼴 재현성 검증도 별도로 필요합니다.

## GitHub에 올리기

ZIP을 빈 폴더에 풀고 실행·검증한 뒤, 아래 순서로 로컬 커밋을 만들 수 있습니다.

```bash
git init -b main
git add .
git commit -m "feat: add exam PDF to PPT converter"
```

`.gitignore`는 `.env`, 글꼴 파일, 원본 PDF/PPTX, 빌드 결과와 의존성을 제외합니다. 커밋 전에 변경 파일 목록에 비밀값과 원본 시험 자료가 없는지 확인하세요. `package-lock.json`은 포함합니다. 이 ZIP에는 원본 PDF·참고 PPT·글꼴 파일·API 키·node_modules·개인 Git 설정을 포함하지 않습니다.

## 코드 위치

- `src/main.jsx`: PDF 업로드·문항 편집·첨자 버튼·원본/슬라이드 미리보기
- `shared/scientific-text.js`: 첨자·밑줄 파싱과 줄 나눔
- `shared/layout.js`: 고정 크기 슬라이드 배치와 분할
- `shared/document.js`: 입력 검증과 20/25문항 번호 검사
- `server/gemini.js`: 전사 프롬프트·JSON 스키마·Gemini 호출
- `server/pptx.js`: 실제 PowerPoint 텍스트와 첨자 생성
- `server/app.js`: 업로드·내보내기·접근 보호
- `docs/reference-analysis.md`: 참고 자료에서 확인한 서식과 적용 범위
