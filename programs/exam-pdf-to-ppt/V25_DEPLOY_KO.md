# v25: 위쪽 그림 조각 누락 및 본문 기호 오인 수정

## 원인과 수정

1. 문항 번호와 같은 높이에서 시작한 그림의 위쪽 조각을 문항 밖으로 판단하는 조건 때문에 11번 그림이 반으로 잘렸습니다. 문항 첫 줄 옆의 그림도 온전히 포함하도록 상단 판정을 수정했습니다.
2. PDF에는 본문 속 원·사각형·삼각형 기호도 작은 이미지로 저장됩니다. 이를 독립 그림으로 취급하면서 12번에서 기호가 크게 삽입됐습니다. 페이지의 일반 글자 높이와 주변 텍스트 위치를 비교해 본문에 삽입된 작은 기호는 그림 목록에서 제외합니다. 필터는 그림 조각 합치기 전에 적용됩니다.

예시 문항 번호나 캡처 좌표를 앱에 고정하지 않았습니다. 업로드한 PDF의 글자·그림 위치로 판단합니다. 기존 글자 추출 지시문, 요청, 응답 처리와 번호 크기·배치 기능은 유지했습니다.

## 검증

- 제공된 PDF에서 11번 전체 그림, 12번 반응 전·후 모형만 캡처되는 것을 확인했습니다.
- 실제 브라우저에서 3·4·5·7번의 기존 캡처도 다시 확인했습니다.
- 그림 좌표를 시험 응답으로 대체하지 않고 PDF에서 직접 탐지했습니다. 글자 분석 응답만 테스트 데이터로 대체했습니다.
- 이미지가 포함된 PPT 다운로드와 29개 자동 검사가 통과했습니다.

## 배포

기존 사이트의 `programs/exam-pdf-to-ppt/`에 압축 해제 폴더의 **index.html과 assets 전체**를 덮어쓰고 기존 방식으로 배포합니다. Worker용 `public-site/`에도 동일 수정본이 반영되어 있습니다.

앱 전용 Worker는 기존 Worker 이름을 확인하고 다음을 실행합니다.

```powershell
npm ci
npx wrangler login
npx wrangler deploy
```

Worker 인증·API 코드는 변경하지 않았습니다. 여러 프로그램용 Worker의 설정은 덮어쓰지 마세요.

배포 후 **Ctrl+F5**로 새로고침하여 **v25**를 확인하고 PDF를 다시 분석하세요. 이전 버전에서 이미 생성한 캡처와 PPT는 자동으로 교정되지 않습니다.

실제 소스: `assets/index-v25.js`, `assets/image-tools-v25.js`, `assets/pdf-figures-v25.js`. 배포 파일 재생성: `npm run build:v25`. 검사: `npm test`.
