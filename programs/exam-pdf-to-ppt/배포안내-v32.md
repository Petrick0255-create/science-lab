# v32 수정 및 배포 안내

## 수정한 문제

- 그림 배경이 회색으로 변하던 v31 밝기 처리를 제거했습니다. PowerPoint의 실제 그림 수정 밝기 +40%, 대비 0%로 만든 테스트 색상표에서 보정값을 측정해 적용합니다. 검정은 검정으로 남고 중간 밝기의 선과 글자는 밝아집니다.
- 미리보기와 내보내기에서 동일하게 보이도록 보정 결과를 캡처 이미지에 직접 적용합니다. 따라서 PowerPoint 그림 서식의 밝기 수치 자체를 +40으로 지정하는 방식은 아닙니다. 추가로 +40을 적용하면 이중 보정됩니다.
- `1/299,792,458`, `1/10,000,000`의 쉼표를 포함한 분모 전체를 하나의 수식으로 묶습니다. 공백으로 구분된 숫자도 지원합니다. 본문과 표에서 동일하게 적용합니다.
- 편집 가능한 세로형 분수, 발문 우선 배치, 밑줄, 표 테두리 2.25pt는 유지합니다.

## 배포

ZIP을 새 폴더에 풀고 `exam-pdf-to-ppt` 폴더 안에서 실행합니다.

```powershell
npm.cmd ci
npx.cmd wrangler login
npx.cmd wrangler deploy
```

로그인 상태라면 login은 생략해도 됩니다. 배포 파일은 public-site에 빌드되어 있습니다. 배포 후 Ctrl+F5 → **v32** 확인 → PDF 다시 분석하세요. 이전 PPT는 자동 수정되지 않습니다. 운영 사이트에 직접 배포하지 않았습니다.

추가 소스 수정 후에는 `npm.cmd run build:v32`를 실행하세요.

## 검증

자동 검사 56개가 통과했습니다. 통합과학 PDF와 저장된 실제 분석 응답으로 웹앱 미리보기와 PPT 내보내기를 검증했습니다. 테스트 PPT를 실제 PowerPoint에서 읽기 전용으로 열고 렌더링하여 검은 그림 배경과 전체 분모 표시를 확인했습니다. 사용자 원본 PPT는 수정하지 않았습니다.

밝기 비교에는 Microsoft의 [PictureEffect API](https://learn.microsoft.com/en-us/office/vba/api/office.pictureeffect)를 사용했습니다. 숫자 분수와 괄호로 구분한 분자·분모를 지원하며, 복잡한 중첩 수식을 모두 변환하는 기능은 아닙니다.
