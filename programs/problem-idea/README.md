# 통합 모의고사 문항 검색

물리학, 화학, 생명과학, 지구과학, 통합과학 문항 9,292개를 발문·보기·선지·유형·해설의 키워드로 검색하는 정적 웹앱입니다.

## 실행

브라우저의 보안 정책 때문에 `index.html`을 파일로 직접 열지 말고 웹 서버로 실행해야 합니다.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다. 일반 정적 호스팅에도 폴더 전체를 그대로 올릴 수 있습니다.

## 검색 데이터 갱신

현재 웹용 스냅샷은 Google Sheets의 `통합 모의고사 문항 DB`를 기준으로 생성되어 있습니다. DB를 갱신한 뒤 같은 스키마의 NDJSON 묶음을 준비하고 아래 명령을 실행합니다.

```bash
node build-index.js /path/to/ndjson-folder
```

입력 파일명은 `chunk_000.ndjson` 형식이어야 합니다. 빌드 스크립트는 검색용 `data/search-index.json`과 문항 상세 데이터 묶음 `data/details/`를 함께 생성합니다.

문항 유형은 `기출분석.xlsx`에서 추출한 `reference/type-map.json`을 문항ID별로 적용하고, 과목별 필터 순서는 `reference/type-catalog.json`을 따릅니다.

## 고3 학년도 보정 규칙

- 6·9·11월은 시험지 연도와 저장 연도가 같습니다.
- 그 밖의 월은 시험지 연도보다 1 큰 학년도로 저장합니다. 예: 시험지 `25 07` → `3S2607xx`.
- 날짜 검색은 시험지 표기 연도를 기준으로 보정합니다. 예: `25 07 생명과학` → `3S2607xx`. 저장 코드는 `3S2607`처럼 직접 검색할 수 있습니다.

## 로컬 파일 연결

문항 이미지 미리보기와 이미지 버튼은 항상 형제 폴더인 `exam-search/data`의 로컬 PNG를 사용합니다. `PDF 로컬 우선`을 켜면 문제·해설 PDF도 같은 자료 폴더를 사용합니다.

```text
science-lab/programs/
├─ problem-idea/   ← 이 ZIP의 파일을 저장하는 위치
└─ exam-search/
   └─ data/        ← 문제·해설 PDF와 문제 이미지가 있는 위치
```

```text
../exam-search/data/고3 기출/생명과학/문제 이미지 파일/3S260701.png
../exam-search/data/고3 기출/생명과학/3S2607.pdf
../exam-search/data/고3 기출/생명과학/3S2607 해설.pdf
```

## 주요 기능

- 여러 검색어의 AND 검색
- 과목별 유형 필터 및 키워드·유형 조합 검색
- 문항ID 직접 검색 (`3S250301` 등)
- 과목·유형·학년 필터와 관련도·연도·번호 정렬
- 로컬 PNG 문항 이미지 미리보기 및 원본 열기
- 문제 PDF와 해설 PDF 바로가기
- 문제·해설 PDF의 Drive/로컬 우선 모드 전환
- URL 검색 조건 공유 (`?q=초전도체&subject=통합과학`)
- 카드에서 문항 유형 수정 및 Google Sheets DB의 `문항 DB!H:H`에 동기화
- 고3 11월 문항을 `25 수능 생명과학 09번` 형식으로 표시·검색
- `평가원만` 체크 시 고3 6월·9월·11월 문항만 검색

## 유형 DB 동기화 연결

원본 DB는 `통합 모의고사 문항 DB`이며, `문항 DB` 탭의 A열 `문항ID`와 H열 `유형`을 사용합니다.

1. 원본 Google Sheets에서 `확장 프로그램 → Apps Script`를 엽니다.
2. `AppsScript-TypeSync.gs`의 코드를 Apps Script 프로젝트에 추가합니다.
3. `setProblemIdeaSyncToken`을 한 번 실행하고 16자 이상의 동기화 키를 저장합니다.
4. Apps Script를 웹 앱으로 새 배포합니다. 실행 사용자는 `나`, 액세스 권한은 이 웹페이지 사용자가 접근 가능한 범위로 설정합니다.
5. 웹페이지의 `DB 연결 설정`에서 배포된 `/exec` URL과 같은 동기화 키를 입력합니다.

수정 중인 유형은 브라우저에 임시 저장됩니다. `유형 DB 동기화`를 누르면 문항ID와 기존 유형을 다시 확인한 뒤 H열만 변경하므로, 다른 곳에서 먼저 바뀐 문항은 덮어쓰지 않고 중단합니다.
